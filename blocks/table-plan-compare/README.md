# table-plan-compare

Custom **table** block. Purpose: Feature x plan comparison grid with grouped plan columns and a recommended plan..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: xwalk container: three single-cell block-field rows (groups, highlight, legend), then one row per Plan Row item with 7 cells [label, plan1..plan6]. First item = column headers. Cell values ':dot:' / ':dot-ring:' / text / empty. Plan columns empty in all rows are dropped..

## Supported variations

No variations.

- Content fields derived from the block's decorate contract.
