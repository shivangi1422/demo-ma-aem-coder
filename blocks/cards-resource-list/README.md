# cards-resource-list

Custom **cards** block. Purpose: Stacked list of resources, each a type icon and a linked title.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: type cell (video | pdf | document, or an icon image) | link cell (linked title).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
