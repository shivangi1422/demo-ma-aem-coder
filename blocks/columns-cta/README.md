# columns-cta

Custom **columns** block. Purpose: side-by-side contact or action options, each a button above a short description.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; each cell: a paragraph with a single link (becomes the button) followed by a description paragraph.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
