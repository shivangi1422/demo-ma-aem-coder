# embed

Custom **embed** block. Purpose: Embed external interactive content or video in a responsive iframe.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = URL (link or plain text); row 2 = optional title (plain text, used as the iframe title; defaults to the link text or 'Embedded content')..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
