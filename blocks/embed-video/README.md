# embed-video

Custom **embed** block. Purpose: Single lazy-loaded third-party video player (Wistia, YouTube, Vimeo).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row: optional poster image, then a link to the video URL (https://fast.wistia.net/embed/iframe/<mediaId>, a wistia.com/medias/<id> URL, YouTube or Vimeo URL).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
