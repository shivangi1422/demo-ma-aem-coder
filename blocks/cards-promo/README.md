# cards-promo

Custom **cards** block. Purpose: Promotional cards: greyscale 3:2 image that colours and zooms on hover, red eyebrow, linked title; whole card clickable; 4/2/1 columns.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: cell 1 image (+ alt); cell 2 rich text with eyebrow paragraph and a title paragraph containing the link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
