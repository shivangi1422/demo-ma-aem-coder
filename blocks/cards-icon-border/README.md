# cards-icon-border

Custom **cards** block. Purpose: Service / feature link cards with a coloured icon, title and description..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One card per row. Icon token (:fa-user-plus:) in its own paragraph, arriving as text or span.icon; h4 title link; description link (kept as a plain link, never a button)..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
