# content-product-detail

Custom **columns** block. Purpose: Product intro text beside a main image + thumbnail gallery.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 0 (block field): richtext text column. Rows 1..N: one Product Image item each (image + imageAlt); the first image is the main image, the rest are thumbnails.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
