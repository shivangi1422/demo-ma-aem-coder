# callout-bar

Custom block. Purpose: a white, shadowed prompt bar with one button that overlaps the start of the next section
(mybeckman.in /service/tech-support "In need of immediate assistance?").

## Authoring (Universal Editor)

Model: `callout-bar` (one rich-text field `text`).

One row, one cell: a prompt paragraph, then a bold link (filled button) or an italic link (outline button).

## Layout

- below 768px: full width, prompt and button stacked and centred, 18px below its place in the flow
- from 768px: 600px wide and centred, prompt left and button right, 40px lower (54px from 992px)

## Supported variations

No variations.
