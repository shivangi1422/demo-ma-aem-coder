# cards-button-caption

Custom **cards** block. Purpose: Contact options: a button per channel with a short caption..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One item per row; the first paragraph holding only a link (plain, bold/italic or p.button-container > a.button) is the button, other paragraphs are captions..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
