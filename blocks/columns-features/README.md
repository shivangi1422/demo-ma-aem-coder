# columns-features

Custom **columns** block. Purpose: Fixed set of side-by-side feature groups (heading + bullet list each).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One Feature Column item per column (UE container item, single richtext cell: H4 heading + bullet list). Document-authored tables may instead use one row with one cell per column; both are accepted.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
