# Service Contact

Use this block to present a section introduction and a responsive set of contact
options.

## Authoring

- Add the section heading and optional introduction in the block's first rich-text
  field.
- Add one contact option per item. Use a heading, a short description, and an
  optional link. Use `tel:` for phone links and `mailto:` for email links.
- The block supports one, two, or three columns depending on the viewport.

The block renders content only; it does not submit forms or send contact data.
