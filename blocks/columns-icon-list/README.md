# columns-icon-list

Custom **columns** block. Purpose: Large image next to a stacked list of icon + label + link items.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 0: one cell with the large image (block field image + imageAlt). Rows 1..N: one Icon Item each: icon image cell | richtext cell (label line, line break, bold link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
