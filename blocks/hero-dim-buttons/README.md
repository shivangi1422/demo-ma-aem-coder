# hero-dim-buttons

Custom **hero** block. Purpose: Page-top hero with a dimmed photo, a heading, subtitle and two calls to action..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Image row then rich-text row. Consecutive paragraphs holding only one link render side by side as buttons: bold link = filled, italic link = outline (plain link = filled)..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
