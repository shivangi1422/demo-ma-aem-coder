# quote

Custom **quote** block. Purpose: Pull quote / testimonial with optional attribution.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = quote (rich text); row 2 = attribution (plain text, optional; omitted when empty). Style select (classes) picks the option..

## Supported variations

| Variation | Option class |
| --- | --- |
| Banner (dark band, upright white text) | `banner` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Banner (dark band, upright white text).
