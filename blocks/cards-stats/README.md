# cards-stats

Custom **cards** block. Purpose: row of key figures, each a bold value over a short label.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one text cell: bold value paragraph (<strong>) followed by a label paragraph.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
