# hero-centered

Custom **hero** block. Purpose: page-opening banner with a full-bleed photo behind a centered heading, intro text and call to action.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image (with alt); row 2: text cell with H1 (or a title graphic picture, kept in the content), intro paragraph and one or more CTA links (each in its own paragraph).

## Supported variations

| Variation | Option class |
| --- | --- |
| Tall (450px) | `tall` |
| Left-aligned (graphic + buttons, no tint) | `left` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Tall (450px), Left-aligned (graphic + buttons, no tint).
