# table-grouped

Custom **table** block. Purpose: Two-column reference table grouped by bold full-width label rows.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per entry: group row = one cell with the group label (or an empty Description); data row = name cell (text or link) | description cell.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
