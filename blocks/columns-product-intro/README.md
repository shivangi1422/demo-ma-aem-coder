# columns-product-intro

Custom **columns** block. Purpose: product page intro: product image beside the H1, introduction, checklist, call-to-action buttons and a 'Resources + Tools' link table.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: image (product picture) | text (H1, paragraph, bulleted checklist, button links: bold = primary, italic = secondary, then a bold-only paragraph label such as 'Resources + Tools' followed by a bulleted list of links).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
