# cards-topic-tiles

Custom **cards** block. Purpose: Text-only link tiles with a decorative arrow and an animated red gradient fill on hover; 3 columns >= 768px, stacked horizontal tiles below.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per tile: cell 1 image (leave empty); cell 2 rich text with one linked title.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
