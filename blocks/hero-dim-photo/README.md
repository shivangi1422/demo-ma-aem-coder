# hero-dim-photo

Custom **hero** block. Purpose: Page-top hero with a dimmed photo and a centred heading, intro and CTA..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Image row then rich-text row. Any paragraph holding only one link (plain, bold/italic or already a button) renders as the outline button..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
