# jump-nav

Custom **jump-nav** block. Purpose: Sticky in-page navigation: pill of anchor links on desktop, a native select below 768px, smooth scroll to the section whose id matches.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per link: a link whose URL is the target section anchor (#latest) and whose text is the label.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
